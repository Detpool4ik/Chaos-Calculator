# ChaosCalculator — Калькулятор хаоса

**Версия:** 0.5.0  
**Платформа:** Android 7.0 (API 24) и выше  
**Язык:** Kotlin  
**Среда разработки:** Android Studio

## О проекте

ChaosCalculator — учебное Android-приложение, которое совмещает обычный калькулятор и необычный интерактивный режим «Хаос».

В обычном режиме приложение выполняет математические вычисления. В режиме хаоса определённые комбинации и последовательности нажатий запускают анимации и забавные эффекты. Математическая логика отделена от интерфейса, поэтому её можно проверять автоматическими тестами.

## Возможности

**Калькулятор:**

- Сложение, вычитание, умножение и деление.
- Цепочки вычислений с соблюдением приоритета операций: `5 + 10 × 2 = 25`.
- Десятичные числа, проценты и смена знака.
- Очистка (`C`) и посимвольное удаление (`⌫`).
- Обработка ошибок, в том числе деления на ноль и незавершённого выражения.
- Трёхстрочный дисплей: предыдущее выражение, текущая операция, число или результат.
- История последних 30 вычислений, копирование результата.
- Светлая и тёмная темы, настройка виброотклика.
- Поддержка вертикальной и горизонтальной ориентации с сохранением состояния.

**Режим «Хаос»:**

- Реакция на вручную введённые комбинации с тройками (но не на случайно полученный результат `33`).
- Постепенное стирание интерфейса при повторных нажатиях `⌫` на пустом вводе.
- Перетаскивание калькулятора и кнопка возврата на место.
- Анимированный полёт знака `%`.
- Чёрная дыра при делении на ноль и восстановление интерфейса перетаскиванием `C`.
- Драка кнопок `+` и `−`, рулетка, сон кнопок и другие эффекты.

Режим хаоса можно выключить — вычисления останутся обычными.

## Как устроен проект

Основной исходный код находится в папке:

`app/src/main/java/ru/kuzel/chaoscalculator/`

| `CalculatorEngine.kt` | Вычисления, работа с математическим выражением, приоритет операций, проценты и проверка ошибок. |
| `ChaosView.kt` | Анимация падения цифр. |
| `SceneView.kt` | Рисование сцен: чёрная дыра, драка кнопок, стирание и другие эффекты. |
| `RouletteView.kt` | Отображение и анимация рулетки. |
| `PercentFlightView.kt` | Анимация вылета и возвращения знака процента. |
| `DragTouchListener.kt` | Обработка жестов перетаскивания. |
| `TapSequence.kt` | Отслеживание серий быстрых нажатий. |
| `JokeState.kt` | Хранение состояния шуточных эффектов и стадий стирания. |

Дополнительные файлы:

- `app/src/test/` — автоматические тесты.

## Как происходит вычисление

Пример: пользователь вводит `5 + 10 × 2 =`.

1. `MainActivity` принимает нажатия кнопок в обработчике `handle()`.
2. `CalculatorEngine` последовательно формирует выражение.
3. При нажатии `=` метод `equals()` вызывает математический разбор выражения.
4. `evaluate()` соблюдает приоритет операций: сначала `10 × 2`, затем `5 + 20`.
5. Метод `render()` в `MainActivity` обновляет дисплей и показывает **25**.

Для чисел используется `BigDecimal`, чтобы избежать типичных погрешностей арифметики с `Float` и `Double`.

## Технологии

- **Kotlin 2.0.21** — язык программирования.
- **Android SDK** — API Android для интерфейса и работы приложения.
- **Jetpack Compose** — трёхстрочный дисплей.
- **Android Views и Canvas** — кнопки и рисование анимаций.

- **Gradle 8.9 / Android Gradle Plugin 8.7.3** — сборка проекта.
- **JUnit и Robolectric** — автоматические проверки.

## Как запустить в Android Studio

1. Скачайте репозиторий через **Code → Download ZIP** или клонируйте его с помощью Git.
2. Откройте Android Studio и выберите **File → Open**.
3. Укажите корневую папку проекта (с файлом `settings.gradle.kts`).
4. Убедитесь, что для Gradle выбран **JDK 17**: **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK**.
5. Дождитесь синхронизации Gradle. Для первой сборки потребуется интернет, чтобы загрузить зависимости.
6. Выберите Android-эмулятор или подключённый телефон с включённой отладкой по USB.
7. Нажмите **Run ▶**.

Минимальная версия Android — **7.0 (API 24)**. Настройки сборки: `compileSdk = 35`, `targetSdk = 35`.

## Проверка проекта

В архивной версии проекта включены автоматические проверки математического движка, поведения интерфейса и эффектов. В отчёте `verification/summary.txt` указаны **88 пройденных тестов** без ошибок.

Запуск unit-тестов из терминала Android Studio в Windows:

```powershell
.\gradlew.bat testDebugUnitTest
```

Сборка APK:

```powershell
.\gradlew.bat assembleDebug
```

Автоматические тесты не заменяют проверку анимаций и управления на реальном телефоне.

## Что показать на защите

1. Обычный расчёт `5 + 10 × 2 = 25` с объяснением приоритета операций.
2. Функции `handle()`, `equals()`, `evaluate()` и `render()`.
3. Переключение между обычным режимом и режимом хаоса.
4. Один-два визуальных эффекта и связанные с ними классы.
5. Сохранение выражения после поворота экрана и запуск тестов.

**Главная идея проекта:** вычисления выполняются в отдельном классе `CalculatorEngine`, а `MainActivity` отвечает за взаимодействие с пользователем. Это делает программу понятнее, удобнее для сопровождения и тестирования.
